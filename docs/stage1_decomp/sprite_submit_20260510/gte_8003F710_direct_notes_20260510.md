# 8003F710 GTE direct boundary notes - 2026-05-10

范围：P0-C1。只服务 `8003F1B4` transform sprite 的 `RTPT + RTPS` carrier；不扩展到完整 TMD/GTE 栈。本轮不编译、不测试、不跑模拟器。

## 本轮实现边界

- `src/pr/pr_psx_gte_direct.h` 增加 `RtptRtps4GapState8003F710`，把 matrix/control/vertex 完整性、depth/division 输入可计算性、SXY/SZ/FLAG/IR0/return gap 拆开记录。
- `GteSzFifo` 增加 `elementKnown`，避免因 RTPT 后 `SZ0` 仍依赖旧 FIFO 状态而把整个 FIFO 误标为完整。
- `GteDivisionTrace` 增加 `inputsKnown` 和 `divideOverflowKnown`，允许记录 `H`/`SZ` 输入，同时不声明 PSX 除法商和 overflow flag 已权威实现。
- `RtptRtps4VertexTrace8003F710` 记录四个顶点经当前 matrix 的线性 transform trace 和 clamp 后 depth 输入，供后续核对 RTPT/RTPS 的 SZ/division 输入。
- `PsxCall8003F710_RotTransPers4RtptRtpsGap()` 保留 `8003F710` 的调度顺序：前三点 RTPT，第四点 RTPS。

## 明确没有关闭的 gap

- `RtptRtps4Output8003F710::known` 仍为 `false`。
- `sxy[0..3].known` 仍为 `false`，没有用默认屏幕坐标或 Win float 坐标冒充 PSX GTE packed SXY。
- `flagAfterRtptKnown`、`flagAfterRtpsKnown`、`flagOrKnown` 仍为 `false`，FLAG bit mapping、saturation、near-plane/overflow 规则未权威闭合。
- `ir0Known` 仍为 `false`，没有猜 depth cue / IR0 side output。
- `returnValueKnown` 仍为 `false`，虽然 `sz3AfterRtps` 字段会保留第四点 depth trace，但不声明 `SZ3 >> 2` 的真实返回值已实现。
- `division[].known` 仍为 `false`，只记录 `H` 和对应 `SZ` 输入；quotient、divide overflow 和 flagBits 仍不是权威输出。
- `szAfterRtpt.known` 和 `szAfterRtps.known` 仍为 `false`，只用 `elementKnown` 标记可计算元素；不把 FIFO/flag 组合误标成完整 GTE 状态。

## 对 `8003F1B4` 的影响

`src/pr/pr_psx_gs_sprite_submit_direct.*` 本轮未改。`8003F1B4` 仍固定 `transformFieldsGap = true`，不会把 transform packet 的 `word2/4/6/8` 接到 SXY，也不会提前关闭 rail sprite geometry gap。

后续 C2 若要接线，必须先补齐或验证：

- PSX GTE projection packed SXY 的固定点除法、OFX/OFY 加法、screen saturation 规则。
- RTPT/RTPS 后 FLAG bit 的具体 OR 语义。
- IR0 / depth side output `$8` 的真实来源。
- `returnValue = SZ3 >> 2` 是否仅依赖最终 RTPS `SZ3`，以及相关 saturation/overflow 对返回值的影响。
