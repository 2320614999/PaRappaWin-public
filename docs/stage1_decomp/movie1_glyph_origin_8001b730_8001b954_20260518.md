# Movie1 glyph origin handoff (`8001B730 -> 8001B954`)

## Conclusion

The Movie1 text display chain builds the PSX origin command `8001B730(24,184,0)` before calling the glyph loop `8001B954`, but the direct `SubmitTextFastSpriteSequenceSub8001B954` command was not carrying that origin into the glyph sequence.  This left `8001B954` to compute glyph local coordinates from `(0,0,0)`, pushing the text y coordinate off the PSX subtitle area.

The fix is to pass `textDrawXSub8001DB00`, `textDrawYSub8001DB00`, and `z=0` from the `8001DB00` display chain into the `8001B954` submit command.

## Boundary

- This is a direct handoff between already translated PSX calls.
- It does not restore native subtitle rendering.
- It does not use renderer defaults, Win text, or resource names as text authority.
- Stage1 script-box glyph submit already had an explicit origin; this closes the Movie1-specific gap.
